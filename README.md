# Accessible Learning — Lab 5 (React + Node.js / Express)

Educational web project supporting students with dyslexia, connecting a React Frontend (from Lab 4) with a Node.js + Express Backend.

## Project Structure
- `src/` — React Frontend (Vite)
- `server/` — Node.js & Express Backend (`server.js`, `data.js`, `package.json`)

## How to Run

### 1. Start Backend (Express)
Open the first terminal in the project root and run:
```bash
cd server
npm install
node server.js
